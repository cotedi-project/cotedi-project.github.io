<p><span data-contrast="none">The «Multiples Calculator» activity combines mathematical concepts with programming using circuit boards, electrical circuits, and their connections. This activity is designed for students aged 10 and above, specifically those in the third cycle of Primary Education, starting from 5th grade. It is planned to be carried out over three 1-hour sessions. The activity can be done in a regular classroom, provided there are tablets or laptops available, or in a computer lab.</span><span data-ccp-props="{&quot;201341983&quot;:0,&quot;335551550&quot;:6,&quot;335551620&quot;:6,&quot;335559738&quot;:120,&quot;335559739&quot;:120,&quot;335559740&quot;:360}"> </span></p>

For this, Lego blocks or similar interlocking manipulatives will be needed. During the second and third sessions, students will use educational boards compatible with Makey Makey to build circuits, observe how connections work, and program the system so that a character announces the color of the piece being touched. Later, the program will be expanded to calculate multiples of 2, 3, and 5.</span><span data-ccp-props="{&quot;201341983&quot;:0,&quot;335551550&quot;:6,&quot;335551620&quot;:6,&quot;335559738&quot;:120,&quot;335559739&quot;:120,&quot;335559740&quot;:360}"> </span></p>

									<p><span data-contrast="none">Would you like to teach your students hands-on concepts about prime and composite numbers, multiples, and divisors? What if we connect these ideas with programming an educational board using Makey Makey connections and create a calculator that computes multiples? Then this is the perfect activity for you. In this guided, step-by-step project, you’ll find everything you need to implement it in your classroom.</span><span data-ccp-props="{&quot;201341983&quot;:0,&quot;335551550&quot;:6,&quot;335551620&quot;:6,&quot;335559738&quot;:120,&quot;335559739&quot;:120,&quot;335559740&quot;:360}"> </span></p>
<p><span data-contrast="none">I propose several playful activities through which students will explore and understand key mathematical concepts. A prime number is represented by a single Lego piece, while a composite number is formed by combining multiple pieces whose values multiply together. Multiples are built by creating a number with Lego pieces and then adding more pieces that represent the multiplication process. Divisors are the values or pieces into which a number can be evenly separated.</span><span data-ccp-props="{&quot;201341983&quot;:0,&quot;335551550&quot;:6,&quot;335551620&quot;:6,&quot;335559738&quot;:120,&quot;335559739&quot;:120,&quot;335559740&quot;:360}"> </span></p>
<p><span data-contrast="none">After exploring these concepts hands-on using Lego blocks, students will move on to creating a multiples calculator using Echidna boards connected via Makey Makey. In the second session, students will learn how to work with the board and how to make the necessary connections. Finally, in the third session, they will apply their knowledge and use programming variables to develop their own multiples calculator.</span><span data-ccp-props="{&quot;201341983&quot;:0,&quot;335551550&quot;:6,&quot;335551620&quot;:6,&quot;335559738&quot;:120,&quot;335559739&quot;:120,&quot;335559740&quot;:360}"> </span></p>								</div>

									<p>This activity is designed for students from the third cycle of Primary Education, starting at age 10 or from 5th grade. It can be carried out in the regular classroom if laptops are available; otherwise, it may need to be conducted in a computer lab.</p>
<p>The proposal includes three activities, each corresponding to a separate one-hour session:</p>
<ul>
<li>Session 1: Prime and composite numbers, multiples, and divisors using Lego.</li>
<li>Session 2: Introduction to an Echidna board and Makey Makey connections.</li>
<li>Session 3: Multiples calculator.</li>
</ul>
<p> </p>
<p><strong>Session 1: Prime and composite numbers, multiples, and divisors using Lego</strong></p>
<p>In this first session, students will explore mathematical concepts such as prime and composite numbers, multiples, and divisors through hands-on activities with Lego blocks. In sessions two and three, they will use Makey Makey connections and program an Echidna board to develop the calculator.</p>
<p>To carry out Session 1, the following materials are required:</p>
<ul>
<li>Tangible materials: LEGO blocks and dice (at least one per group).</li>
<li>Electronic device: Tablets, one per student, to complete a final Kahoot activity. However, this final part can also be done offline if needed.</li>
</ul>
<p>The activities in this session will be guided, with concept explanations followed by various “Lego games” to reinforce understanding. A total of three activities will be conducted during this session.</p>
<p><em>Activity 1: Building Numbers up to 20 with Lego</em></p>
<p>Students are shown an image containing several numbers and asked if they notice any patterns or connections between them. If they do, they are encouraged to explain what they see and why.</p>
<p>The concepts of prime and composite numbers are introduced. A prime number is represented by a single Lego piece, while a composite number is represented using multiple pieces.</p>
<ul>
<li>In this activity, each prime number is associated with a specific color: blue (2), yellow (3), pink (5), white (7), red (11, 13, 17, and 19). Figure 1 shows the color code used in this session.</li>
</ul>

<p><em>Figure 1. Multiples. Session 1. Image showing the color code.</em></p>
<ul>
<li>The teacher demonstrates how to build the numbers up to 7 using Lego pieces.</li>
<li>Then, students are asked to construct the numbers from 2 to 20 using Lego blocks, applying the color code and concepts they’ve learned.</li>
</ul>
<p>An example of the outcome from this activity is shown in Figure 2.</p>

<p> </p>
<p><em>Activity 2: Creating Multiples with Lego Pieces</em></p>
<ul>
<li>Students are introduced to the idea that multiples are built by starting with a Lego piece representing a number and then adding (multiplying) pieces to form its multiples.</li>
<li>Taking turns, students roll a die and build the first five multiples of the number they rolled. Figure 3 shows examples of the multiples of 2, 3, and 4 from left to right.</li>
<li>As a variation, students can roll the die twice, then either add or multiply the two numbers, and create the first three multiples of the resulting number.</li>
</ul>
<p><img loading="lazy" decoding="async" class="alignnone size-medium wp-image-2097" src="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_12-300x169.jpg" alt="" width="300" height="169" srcset="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_12-300x169.jpg 300w, https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_12.jpg 508w" sizes="(max-width: 300px) 100vw, 300px" /></p>
<p><em>Figure 3.Multiples. Session 1. Multiples activity with Lego.</em></p>
<p> </p>
<p><em>Activity 3: Divisors Using Lego Pieces</em></p>
<p>Students are taught that divisors are numbers that divide another number evenly, with no remainder. Using Lego pieces, they can visually explore how a number is made up of its divisors. A composite number, in this case, can be represented by the combination of Lego blocks used to build it.</p>
<p>For example, the number 12 can be built using two blue pieces (value 2 each) and one yellow piece (value 3). This shows that 12 is made up of the numbers 2 and 3, but also the products of these values:</p>
<p>2 × 2 = 4</p>
<p>2 × 3 = 6</p>
<p>2 × 2 × 3 = 12</p>
<p>Therefore, the divisors of 12 are: 2, 3, 4, 6, and 12.</p>
<p> </p>
<p>Figure 4 illustrates how this concept is explained during the presentation.</p>
<p><img loading="lazy" decoding="async" class="alignnone size-medium wp-image-2098" src="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_13-300x166.jpg" alt="" width="300" height="166" srcset="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_13-300x166.jpg 300w, https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_13.jpg 469w" sizes="(max-width: 300px) 100vw, 300px" /></p>
<p><em>Figure 4.Multiples. Session 1. Slide explaining the concept of divisors</em></p>
<p> </p>
<p>Students are then asked to access the Kahoot quiz on divisors via this link: <a href="https://bit.ly/4iVXI0S">https://bit.ly/4iVXI0S</a>  and complete the test.</p>
<p>All these activities were designed after watching the Matesenelinst video, available at <a href="https://bit.ly/4iB8AkW">https://bit.ly/4iB8AkW</a>.</p>
<p><strong>Session 2: Introduction to an Echidna Board and Makey Makey Connections</strong></p>
<p>In the second session, students are introduced to programming with boards using Makey Makey connections. The main objectives of this activity are:</p>
<ul>
<li>To become familiar with technology-related terms such as microcontroller, input elements, and output elements of a board.</li>
<li>To learn about essential programming blocks, including looks, events, control, and board-specific blocks.</li>
<li>To create electrical circuits using Makey Makey connections.</li>
</ul>
<p>To begin programming boards using a block-based language such as Scratch.</p>
<p>Materials required for session 2:</p>
<ul>
<li>Devices:
<ul>
<li>Echidna Shield boards connected to an Arduino Uno or Echidna Black boards.</li>
<li>Four crocodile-style alligator clip cables per board.</li>
<li>Computers with Echidna ML software installed. This desktop application includes a modified version of Scratch with additional blocks to program Echidna boards and also supports AI modules through Learning ML.</li>
</ul>
</li>
<li>Tangible materials: Aluminum foil or other conductive material, paper clips, cardboard with aluminum foil, and Lego blocks.</li>
</ul>
<p>Figure 5 shows an image of the materials used.</p>
<p>The proposed activities will be delivered in two formats depending on the students&#8217; prior knowledge:</p>
<ul>
<li>Guided exercises for those new to electronics.</li>
<li>Challenge-based tasks for students with existing experience.</li>
</ul>
<p><img loading="lazy" decoding="async" class="alignnone size-medium wp-image-2099" src="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_14-300x226.jpg" alt="" width="300" height="226" srcset="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_14-300x226.jpg 300w, https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_14.jpg 506w" sizes="(max-width: 300px) 100vw, 300px" /></p>
<p><em>Figure 5. Multiples. Session 2. Examples of devices and materials used.</em></p>
<p>During the second session, students will complete the following three activities.</p>
<p> </p>
<p><em>Activity 1: Understanding What a Board Is (10 minutes)</em></p>
<p>A brief presentation introduces the components of the board, using a visual comparison between the board and the human body. The board acts as the brain, some components as senses that receive information, and others as limbs that execute commands.</p>
<p>For example, if I touch something hot, my brain detects it and sends the command to withdraw my hand. Similarly, the board collects input, processes it (like a brain), and sends instructions to other components to perform actions.</p>
<p>Students will then classify various elements as either input or output devices.</p>
<p>This presentation is based on the work of Jorge Lobo, José Pujol, and Xabier Rosas, available at the Echidna website: <a href="https://echidna.es/didactica/primaria/actividad-steam-01/">https://echidna.es/didactica/primaria/actividad-steam-01/</a>.</p>
<p> </p>
<p><em>Activity 2: Connecting the Circuit (10 minutes)</em></p>
<p>The concept of a circuit is briefly explained, followed by instructions on connecting the board with 3 sensors and a ground connection.</p>
<p>Figure 6 shows how to connect the devices properly. Clips must grip the connector firmly rather than being inserted through holes, as incorrect connections prevent circuit completion.</p>
<p><img loading="lazy" decoding="async" class="alignnone size-medium wp-image-2100" src="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_15-300x169.jpg" alt="" width="300" height="169" srcset="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_15-300x169.jpg 300w, https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_15.jpg 508w" sizes="(max-width: 300px) 100vw, 300px" /></p>
<p><em>Figure 6. Multiples. Session 2. Connecting a circuit.</em></p>
<p> </p>
<p><em>Activity 3: Programming a Makey Makey Connection Circuit (20 minutes)</em></p>
<p>After assembling the circuit, students program it so that a cat character says different words depending on which sensor is touched. This reinforces the idea of the board as the «brain» that responds when the circuit is closed.</p>
<p>For example, touching the foil on the blue Lego piece triggers the character to say “blue.” The same applies to the other two colors.</p>
<p>Figure 7 shows an example of classroom activity and solution. For beginners, the necessary programming blocks are introduced and explained. Students arrange the blocks correctly to program the blue color response, then test their work.</p>
<p><img loading="lazy" decoding="async" class="alignnone size-medium wp-image-2101" src="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_16-300x163.jpg" alt="" width="300" height="163" srcset="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_16-300x163.jpg 300w, https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_16.jpg 491w" sizes="(max-width: 300px) 100vw, 300px" /></p>
<p><em>Figure 7. Multiples. Activity 2. The cat says the colors of the Lego pieces.</em></p>
<p> </p>
<p>Finally, they duplicate the program for the yellow and pink colors and verify functionality. Figure 8 presents an example of a programmed circuit in this activity, showing the developed program, the character responding with the correct color, and the board connected to a computer. It also illustrates how students must touch the clip and conductive material to close the circuit and trigger the response.</p>

<p><em>Figure 8.Multiples. Session 2. Example of programming in the classroom.</em></p>
<p><strong>Session 3: Multiples Calculator.</strong></p>
<p>In the third session, students will learn how to create a multiples calculator using the knowledge gained in the previous two sessions. The concept of a variable will be introduced to accumulate the results of the calculations performed with the calculator. A variable is a data element that changes but does not modify the program itself. In this case, the variable will be numeric and represent the result of multiplying the base number. It is essential to initialize the variable with the value 1 because if it starts at 0 (the default), the program will not work—any number multiplied by 0 is 0. Starting at 1 ensures that any number multiplied by 1 remains that number.</p>
<p>For example, the variable begins as 1, and each time the board detects a circuit connection, it multiplies the variable by the associated value. If the blue piece is touched, the variable (1) is multiplied by 2, becoming 2. Touching the blue piece again multiplies the variable by 2, changing its value to 4. Touching the pink piece multiplies the variable by 5, changing its value to 20 (5 × 4), and so on. To start over, clicking the green flag resets the variable to 1 as the program restarts.</p>
<p>The materials used are the same as in session two.</p>
<p>To guide the creation of the multiples calculator, the following steps are proposed:</p>
<ol>
<li>Review concepts from previous sessions:</li>
</ol>
<ul>
<li>What is a prime number? What is a multiple?</li>
<li>Input and output elements of a board.</li>
<li>What is a microcontroller?</li>
<li>Makey Makey connections and what is a circuit.</li>
</ul>
<ol start="2">
<li>Explanation of the variable concept in programming: A variable is a place to store information that can change during program execution. We use a numeric variable here. Explain why the default value must be changed from 0 to 1 in Scratch, since 1 is the multiplicative identity (0 × any number = 0, but 1 × any number = that number).</li>
<li>Presentation of the session challenge:</li>
</ol>
<ul>
<li>Each time a Lego piece is touched, it multiplies by its associated value.</li>
<li>The new value updates and replaces the previous result (like a calculator’s memory).</li>
<li>The ability to reset the value to 1 when needed.</li>
</ul>
<ol start="4">
<li>Programming the calculator:</li>
</ol>
<ul>
<li>Allow students time to think about how to solve the problem and which blocks to use. For beginners, provide guidance on necessary blocks.</li>
<li>Display the blocks in a scrambled order (as shown in Figure 9) and ask students to arrange them correctly to create the program.</li>
</ul>
<p> </p>
<p><img loading="lazy" decoding="async" class="alignnone size-medium wp-image-2103" src="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_18-300x166.jpg" alt="" width="300" height="166" srcset="https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_18-300x166.jpg 300w, https://imaginatic.es/wp-content/uploads/2025/06/Screenshot_18.jpg 557w" sizes="(max-width: 300px) 100vw, 300px" /></p>
<p><em>Figure 9. Multiples. Session 3. Unordered blocks and correct programming</em></p>
<ul>
<li>After some time, provide the correct solution so they can check for errors or confirm accuracy. Start with programming number 2. Once this is done, students can duplicate and adjust the program to work for numbers 3 and 5 by changing the numeric values and Makey Makey connections from A0 to A2 and A4.</li>
<li>Ask students to test that their programs work correctly.</li>
<li>Encourage students to test very large numbers to observe limitations when storing large values in numeric variables.</li>
</ul>

									<p>After completing the activity, we observed that students are motivated to engage with and understand all the content, even if they had no prior experience with technological topics such as board programming or circuit connections. However, caution is needed, as students sometimes confuse basic concepts, for example, classifying screens as input devices instead of output devices, or incorrectly connecting crocodile clips by inserting them into holes instead of pinching the metal ring.</p>
<p>Regarding the math session, students enjoy it and improve their understanding of concepts like prime and composite numbers, multiples, and divisors. Working cooperatively, they help and correct each other when mistakes are noticed. In the Kahoot activity, however, care is needed because some students were more focused on being the first to answer rather than answering correctly or taking time to understand the questions. Despite the questions being simple and supported by images with hints, there were quite a few careless mistakes made in the rush to be first.</p>
<p>When setting up the boards, it’s important to note that computers do not come with the necessary software installed by default, nor do the boards get recognized automatically the first time they are plugged in. Therefore, time must be allocated beforehand to install drivers and the programming software.</p>
<p>Another point to keep in mind is that the boards have a switch to select between sensor mode or Makey Makey mode. It must be set to Makey Makey, not sensors. Students sometimes change this setting while using the boards, which can cause errors when running the program.</p>								</div>

<p>Finally, I encourage teachers to implement activities like this in the classroom, as they also present challenges for us as educators, sometimes pushing us out of our comfort zones and helping us grow in our own learning.</p>

<td width="198">
<p>Activity Protocol and Guidelines</p>
</td>
<td width="473">
<p><strong>Session 1: Prime and composite numbers, multiples, and divisors with Lego.</strong></p>
<p><em>Session 1, Activity 1. Create numbers up to 20 with Lego</em></p>
<p>§  An image with numbers is shown (see Figure 1), and students are asked if they see a connection between those numbers, and if so, to say which and why.</p>
<p>§  It is explained what a prime number and a composite number are. The concept of prime is associated with a single piece, and composite with more than one piece.</p>
<p>§  They are shown how to make numbers up to 7.</p>
<p>§  They are asked to create numbers from 2 to 20 using Lego pieces.</p>
<p><em>Session 1, Activity 2. Creating multiples with Lego pieces</em></p>
<p>§  The dynamic is explained: multiples are created by taking the number piece and adding (multiplying) the multiple (see Figure 2).</p>
<p>§  Students take turns rolling the die and create the first 5 multiples of the number they rolled.</p>
<p>§  A variant is that they either add or multiply the given number and create the first 3 multiples of that number.</p>
<p><em>Session 1, Activity 3. Divisors with Lego pieces</em></p>
<p>§  It is explained that divisors are numbers by which you can divide another number with a remainder of 0.</p>
<p>§  With Lego pieces, we can verify that these numbers are the ones that compose that number. Visually, we can check that a composite number is formed by the numbers (pieces) that make it up (see Figure 4). For example: 12 can be formed by 2 blue pieces (value 2 each) and one yellow piece (value 3). So, the numbers that compose 12 are the values of each piece: 2 and 3, but also their multiplication: 2×2 = 4; 2×3 = 6; and 2×2×3 = 12, so the divisors of 12 are: 2, 3, 4, 6, and 12.</p>
<p>§  Students are asked to join the Kahoot (<a href="https://bit.ly/4iVXI0S">https://bit.ly/4iVXI0S</a>) and take the divisors quiz.</p>
<p><strong>Session 2: Introduction to an Echidna board and Makey Makey connections.</strong></p>
<p><em>Session 2, Activity 1. Understanding what a board is (10 minutes)</em></p>
<p>§  Brief presentation about the elements of the board. Visual image and comparison of the board with the human body. The board is the brain, and some components are the senses that receive information, and others execute actions like limbs. For example, if I touch something hot, my brain detects it and sends the order to move my hand away.</p>
<p>§  On the board, some elements collect information, the program (brain) executes, and sends an order to another element to perform a specific action.</p>
<p><em>Session 2, Activity 2. Connecting the circuit (10 minutes)</em></p>
<p>Brief explanation of what a circuit is and then how to connect the board with 3 sensors and a ground (see Figure 6).</p>
<p><em>Session 2, Activity 3. Programming a Makey Makey circuit (20 minutes)</em></p>
<p> Once the circuit is explained and assembled, students will create a program where a cat says different things depending on the sensor connected. This helps to reinforce the idea that the board is like the “brain,” and what we “touch” closes the circuit, triggering a response — the colour of the piece touched. For example, if we touch the foil on the blue piece, the cat or chosen character says “blue”; if yellow piece, it says “yellow”; if pink piece, it says “pink” (see Figure 7).</p>
<p><strong>Session 3: Multiples calculator.</strong></p>
<p>The following steps are proposed as a guide for this session:</p>
<p>1.       Review concepts from previous sessions:</p>
<p>o   What is a prime number? What is a multiple?</p>
<p>o   Input and output elements of a board.</p>
<p>o   What a microcontroller is.</p>
<p>o   Makey Makey connections and what a circuit is.</p>
<p>2.       Explain the concept of variables in programming: Explain that a variable is a place to store information that can be modified during program execution. In this case, a numeric variable will be used. Also explain why it is necessary to change the default variable value from 0 to 1 in Scratch (due to the neutral element of multiplication). Since we multiply by a number, we must start at 1 because 0 times any number is 0, and 1 time any number is the number itself.</p>
<p>3.       Present the challenge for the session:</p>
<p>o   We want each Lego piece touched to multiply by its associated value.</p>
<p>o   We want that value to update the previous one and store it (like the calculator’s result display).</p>
<p>o   We want to be able to reset to 1 whenever needed to start over.</p>
<p>4.       Programming the calculator (see Figure 10):</p>
<p>o   Let students think about how to solve the problem or what blocks are needed. If the group is just starting, help by indicating which blocks will be needed.</p>
<p>o   Show the blocks unordered on screen and ask them to create the program step-by-step. First program the number 2 value. Then explain how to duplicate this to create programs for values 3 and 5.</p>
<p>o   After some time, provide the completed program so they can check for errors or verify it’s correct, and then continue programming for numbers 3 and 5 by duplicating necessary blocks. Change values 2 to 3 and 5, and connections from A0 to A2 and A4.</p>
<p>o   Once programmed, ask them to test if it works.</p>
<p>o   Allow them to create endless numbers or go to infinity to observe issues with storing large values when using numeric variables.</p>
